🎵 Music Player Web App

A clean and responsive music player built using **HTML**, **CSS**, and **JavaScript**. This project allows users to play, pause, skip tracks, and view song progress, all wrapped in a modern UI.

🚀 Features

- 🔊 Play/Pause functionality  
- ⏮️ Next & Previous track controls  
- 📊 Interactive progress bar  
- 🎨 Clean, responsive UI design  
- 📱 Mobile-friendly layout  

 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
